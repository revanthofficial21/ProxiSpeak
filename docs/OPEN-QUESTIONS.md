## When you add an idea, say which it is

1. **A fix** — something is wrong. Highest priority, do it immediately.
2. **A requirement** — the brief or the reviewer expects it. Do it next.
3. **A nicety** — it would be better, but nothing breaks without it. Only if the
   first two are clear.
