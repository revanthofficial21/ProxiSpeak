# ProxiSpeak — Geospatial Proximity Audio Ecosystem

A real-time virtual collaboration environment designed to connect users through avatar movement and proximity-aware audio.

**Technology Stack:** React, Node.js, Express.js, Socket.IO, MongoDB

## 1. Project Overview

ProxiSpeak is a full-stack web application designed to create a shared 2D virtual environment where users are represented by avatars. The application aims to synchronize avatar positions between connected browser clients and provide a foundation for proximity-based audio communication.

The project combines a React-based frontend, a Node.js backend, real-time communication through Socket.IO, and planned MongoDB integration for persistent position data and spatial queries.

## 2. Problem Statement

Traditional remote collaboration tools do not naturally recreate the experience of moving through a shared environment and interacting with nearby participants.

ProxiSpeak aims to address this limitation by providing a virtual space where users can move around, observe other participants, and eventually communicate through distance-aware audio interactions.

## 3. Project Objectives

- Develop a shared 2D virtual environment.
- Synchronize avatar positions between connected clients.
- Manage player connections and disconnections in real time.
- Design a database structure for player and position data.
- Prepare for proximity calculations and spatial queries.
- Establish a foundation for real-time voice communication.
